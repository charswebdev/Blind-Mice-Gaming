## Description

A graphical alt manager. The window should feel like a vault of characters: a roster on the left, and the selected character’s pages on the right. It gathers its own snapshots. It does not copy AltVault or Altoholic art or code. Both of those addons are All Rights Reserved. DataStore is not vendored. Each flavor is its own addon, its own SavedVariables, and its own updater row when it ships.

Midnight is the first flavor. The other flavors come after Midnight is playable. Season of Discovery is out. `_classic_beta_` is never an install folder.

The long notes, the open questions, and the drawings live in [`BMG-Alt-Manager/`](BMG-Alt-Manager/README.md). This file is the product record. Charlotte approved the plan on 2026-10-29. Phase 1 code started on 2026-10-30 in `BMGAM`. It was copied into the retail AddOns folder for playtest the same day. Retail 1.0.1 is in the updater catalog, with the account, quest, achievement, and manuscript addons.

## Features

Locked so far:

- The window stays closed until `/bmgam`, the minimap button, or the Titan Panel launcher opens it.
- On open, the selected character is the one the player is logged into. The right page says “Logged in now” for that character.
- Left roster, one bordered card per character. Above the roster, Sort By is Class, Faction, Item Level, Gold, Level, Race, or Realm, and Order is Ascending or Descending. The choice is remembered. Line 1 is the real class icon and the name in gold. Line 2 is Level, Race, then Item Level in the item’s quality color. Line 3 is Server, then Faction, meaning Alliance or Horde. Alliance is blue. Horde is red. Line 4 is Money, with a gold coin, a silver coin, and a copper coin beside the amounts.
- The right header uses the real race portrait, not the class icon.
- Midnight tabs, left to right: Overview, Gear, Bags, Bank, Professions, Currency, Reputation, Mail, Auction, Quests, Achievements, Collections, Vault. Buttons are pictures. Tooltips will name them. Vault is Midnight only. The icons are smaller so the row fits. Gear has no search box. Every other tab has one.
- Reputation names appear only on the Reputation page. Alliance and Horde stay on the character card.
- Overview is the page that opens when a character is selected. The approved reference is `docs/Projects/BMG-Alt-Manager/reference/overview-page-full.jpg`.
- The approved Gear reference is `docs/Projects/BMG-Alt-Manager/reference/gear-page-full.jpg`: roster on the left, two-column gear list on the right, with durability, enchant, and gems. A slot with nothing equipped says Empty Slot. At 0 durability the row shows 0 / maximum in red. The ranged slot appears only on a flavor whose client has it.
- A flavor hides a tab it does not have. Midnight shows all thirteen. Era, Anniversary, MoP, and Forever leave Vault out. A collection header that client lacks is left off. A flavor with no guild bank leaves that section off.

## Sources and data

| Source | Role |
|--------|------|
| WoW client textures | Class icons, race portraits, item icons, coin icons. The addon calls `SetTexture` on the client file. It does not ship copies of those textures |
| Original art in `BMG-Alt-Manager/reference/` | Addon icon, close button, settings button, and the tab pictures. These are the pictures that have no Blizzard file |
| AltVault (Maygus11) | Layout reference only. Do not copy art or code |
| Altoholic / DataStore (Thaoky) | Data-model reference only: one snapshot per character, log each alt, bank and mail only while those windows are open. Do not vendor DataStore |
| `BMGAM/Data/QuestMaps.lua` | Quest id to map id. The client’s quest-pin table supplies the map. A quest with no pin uses a stored map id. The zone name is read from the client map |
| `BMGAM/Data/AchievementOrder.lua` | Category id to the order Blizzard uses. The name and the parent come from the client |

Scan rules, once code starts: bags and worn gear on login. Currencies, reputation, the quest log, completed quests, achievements, collections, vault slot status, and the Overview fields on login. The new-mail notice is read on login. A letter sent to a character on this account is saved on that character when it is sent. The full inbox is read while the mailbox is open, and that list stays, with the days counting down. Bank and guild bank only while those frames are open. Auctions and bids are read on login for the character who is logged in. Professions when the profession window opens. Each alt must be logged in once. Account-wide SavedVariables, one copy per flavor. Do not store secrets or full tooltip text. Drop Midnight and Forever secret values.
