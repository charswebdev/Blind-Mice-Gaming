## Full Overview page with the roster

![Roster on the left and the Overview page on the right](reference/overview-page-full.jpg)

Approved on 2026-10-29, including this drawing. This is the design reference for the Midnight window with the Overview page open. The file is [overview-page-full.jpg](reference/overview-page-full.jpg). The Overview tab is the only lit tab. It is the page shown when a character is selected. Class, Hero, and Specialization sit at the top. Stats follow. Guild has its own header in bold gold, and the guild name under it is bold bright white. This sample says Not in Guild. Under Guild, Delver's Journey sits beside Prey, and Traveler's Journey sits beside Hearthstone Location. The first three show progress and rank. Hearthstone Location shows the place. Each heading line sits below its title. Class, Hero, Specialization, and the stat labels are bold bright yellow. The names and numbers beside them are bold bright white. Talent names stay bold bright yellow. Each talent row is an icon and a bold name, and only talents the player has taken are listed. One name is hovered so the full talent tooltip can be seen. That text is not stored. Hero, specialization, stats, and talent names are picture samples.

## Forget a character

![Trash can on the name line, and the confirmation box](reference/forget-character.jpg)

Approved on 2026-10-29. The file is [forget-character.jpg](reference/forget-character.jpg). The trash can is on the far right of the selected character’s name line. The button is [trash-button.jpg](reference/trash-button.jpg): a dark iron plate, a bright gold border, and a dimensional gold can with the lid tilted open. The confirmation box in the picture is what opens after the trash is clicked. It is not always on the page. Hovering the trash says **Forget this character**. **Cancel** keeps the character. **Forget** removes that character from this flavor’s roster only.

## Settings page
